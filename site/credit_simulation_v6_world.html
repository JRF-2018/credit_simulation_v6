為替 e(C の通貨の価値)と成長率

つなぎ方(1 期 = 0.1 年)

// 貿易: 地域 j の支出 D_j のうち m_j を輸入。Z[i, j] = 地域 j の支出のうち地域 i の生産になる割合
Y = Z (C Y + a)　(連立一次方程式。生産能力を超えた分は、すべての買い手に同じ割合で割り当て、残りは強制貯蓄)
// 金融: hold[j, i] = 地域 j の企業・政府への請求権のうち、地域 i の金利生活者が持つ割合
金利生活者 i の受け取り = Σ_j hold[j, i]·(r_L,j L_j + r_cb B_j + 配当_j) + r_cb S_i
// 会計を閉じる決済残高
ΔS_i = 経常収支_i − ポートフォリオ投資_i,　Σ_i S_i = 0,　世界の経常収支の和 = 0
// 中核と周辺(使うとき): 支出の配分は売り手の生産能力と競争力 A に比例
S_ij ∝ K_i A_i^θ φ^[i≠j],　d ln A_i/dt = v (g_i − ḡ) − χ (u_i − ū) − η ln A_i
// 通貨が別々のとき: 地域の間の流れを為替 e で換算。輸入は相対価格に反応(弾力性 η)
変動相場: d ln e/dt = k_u (u_C − u_B)(または k_ca × 経常収支_C / Y_C)
このモデルには物価がない。為替の動きは、そのまま恒久的な実質為替レートの変化になる。だから、通貨の設定では、効果の向きだけを読み、大きさは読まないこと。
釣り合いの取れた成長経路の上では、世界の合計は、流れで重み付けたパラメータの一国モデルで厳密に描ける(リポジトリの Lean の定理 A)。ショックや為替があると、そのずれが出る。
