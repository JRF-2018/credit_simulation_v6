金融・制度

国債金利でもある。利子は金利生活者の所得になる。
金利の制度では貸出金利への税 (r+spread)/(1−ρ)。量の制度では信用の上限 (1−ρ)H/(ρ+cu)。
量の制度のときだけ効く。
現金/預金比。実効準備率 = ρ + cu。
E = 期待利潤 / (r_L + prem)。下がると「株式的富というペテンへの信頼」が高まる。
借入の上限 L ≤ λ(E + K)。

分配・需要・投資

低いほど利払いが需要から漏れる(v5 の s_eff の正体)。
株式的富が投資を動かす強さ(トービンの q)。
E が縮むときに損耗が増える倍率(v5 から継承)。

国家・労働・ショック

国債比率が 0.6 を超えた分に応じて税率を上げる強さ。

モデル方程式 v6(1 期 = 0.1 年)

// 貸出金利: 無利子の準備の分の割り増し + 貸倒れリスク
r_L = (r_cb + spread)/(1 − ρ) + spread_loss · min(貸倒れ率, 0.1)
// 株式的富: 期待利潤 Π^e の資本還元(v5 の E = K^α/(r+δ) に代わる)
E = Π^e / (r_L + prem)　　Π^e は利潤 Π を 2 年の時定数で追う
// 投資の希望(前の期の利潤率とトービンの q に反応)
I^des/K = δ0 + g0 + g1·Π/K + g2·(u − 0.85) + g_q·(E/K − q_ref)
// 借入: 内部資金で足りない分。担保の上限を超えると返済(量の制度ではさらに信用の上限)
ΔL = softmin(I^des − 内部資金, (λ(E+K) − L)/T_adj [, ((1−ρ)H/(ρ+cu) − L − B)/T_adj])
// 所得: 需要が決める(利子・配当は金利生活者の所得として戻る)
Y = c_w(1−τ)ωY + c_r(1−τ)(r_L L + r_cb B + 配当) + c_v(L+B) + I + G　(生産能力 u_max·K/v を超えた分は強制貯蓄)
Π = (1−ω)Y − δ0 K − r_L L　　配当 = payout·Π
// 結果として出てくる量(v5 では仮定だったもの)
Φ = r_L L / Y(利払い負担率)　θ* = ((1−ω)Y − δ0 K)/Y(利払い前の純利潤分配率)　ρ_eff = ρ + cu
// ストック
K ← K + (I − δK)dt,　δ = δ0(1 + κ·stress_E)　　L ← L + (ΔL − 貸倒れ)dt　　B ← B + (G + r_cb B − 税)dt
初期値は、ショックなしで 300 年走らせた釣り合いの取れた経路の比率に置いている。ショックの値を入れて「▶ 実行」すると、同じパラメータでショックだけを外した基準経路と比べて表示する。
